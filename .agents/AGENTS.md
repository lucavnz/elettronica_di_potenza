# Regola per la presa Appunti Elettronica di Potenza

Quando l'utente chiede spiegazioni su delle slide o su un concetto (e spesso fa lui stesso un ragionamento per verificare se ha capito):
1. Rispondi alle sue domande, conferma le sue intuizioni o correggi eventuali errori. NON TOCCARE NESSUN FILE MENTRE STAI SPIEGANDO O RISPONDENDO.
2. Continua a interagire, chiarire i dubbi e rispondere alle domande finché l'utente non dice esplicitamente di passare oltre (es. "adesso slide 18" o "nuova slide").
3. SOLO E SOLTANTO DOPO che l'utente è passato a un nuovo argomento, aggiorna (o crea) AUTONOMAMENTE il file `Appunti.md` nella cartella in cui si trovano le slide/PDF correnti inserendo la sintesi della discussione precedente.
4. Il file `Appunti.md` deve contenere una sintesi chiara e ordinata delle conclusioni a cui siete arrivati. Scrivi nello stile informale, diretto e discorsivo tipico dell'utente, includendo anche le equazioni in formato LaTeX in modo leggibile.
5. Se il file `Appunti.md` esiste già, non cancellare le spiegazioni precedenti! Aggiungi i nuovi concetti, oppure aggiorna/sovrascrivi solo le parti specifiche se la discussione le ha corrette o approfondite. Deve diventare il quaderno degli appunti definitivo dell'utente per quel capitolo.
